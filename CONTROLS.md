# Controls

`Mod` is `Ctrl` on Windows and `Cmd` on macOS.

## Desktop overlay

| Action | Shortcut |
| --- | --- |
| Click-through on / off | `Mod+Shift+A` |
| Show / hide | `Mod+Shift+H` |
| Scale overlay | `Mod+Shift+Up` / `Mod+Shift+Down` |
| Scale buttons and text | `Mod+Shift+Plus` / `Mod+Shift+Minus` |
| Opacity | `Mod+Shift+Left` / `Mod+Shift+Right` |
| Quit | `Mod+Shift+Q` |
| Move the phone | Drag the frame or the header |

## Map

| Action | Mouse | Touch |
| --- | --- | --- |
| Zoom | Scroll | Pinch |
| Pan | Right or middle drag, or drag empty space with the Move tool | Two fingers, or one finger with the Move tool |
| Rotate | `Alt`+scroll, or ↺ ↻ | Twist two fingers, or ↺ ↻ |
| North up | Click the compass | Tap the compass |
| Load a map | Maps tab, drag and drop an image, or `Mod+V` | Maps tab |

## Editing

| Action | Shortcut |
| --- | --- |
| Undo | `Mod+Z` or the undo button |
| Delete selection | `Delete` / `Backspace` or the trash button |
| Clear selection | `Esc` |
| Confirm / cancel text | `Enter` / `Esc` |
| Edit text in a shape, sticky note or frame | Double-click it, or select it and press the pencil |
| Move an item | Move tool, drag it |
| Move a frame and everything in it | Move tool, drag the frame's title or border |
| Rotate an item | Drag the round handle above it, or ↺ ↻ in the selection bar for 15° steps |
| Free rotation | Hold `Alt` while dragging the handle |
| Resize an item | Type a size in the selection bar |
| Reattach a connector | Select it and drag either end onto a shape, note, image or symbol |
| Recolor | Select an item, then pick a color |
| Cancel a bearing | `Esc` |

## Tools

| Tool | Use |
| --- | --- |
| Move | Select, move and pan |
| Pen | Freehand drawing. Smart shapes turns sketches into clean shapes and lines |
| Highlighter | Wide, see-through strokes |
| Connector | Straight, elbow or curved lines with optional arrowheads that stick to what they touch |
| Shapes | Rectangle, circle, triangle, diamond, star, hexagon and callout, with fill and dashed options |
| Sticky note | Click to place and type |
| Frame | Drag out a named area |
| Fire arc | Arc of fire. Drag the arm handles to adjust |
| Lasso | Draw around items to select several at once |
| Text | Click to place a label |
| Number badge | Numbered markers that count up |
| Waypoint | Named pins, listed in the Waypoints tab |
| Symbols | MIL-STD-2525 and APP-6 unit symbols |
| Measure bearing | Click two points for bearing and distance |
| Ping | Flash a spot for everyone in the room |
| Eraser | Erase drawings. Images are only deleted by selecting them |
